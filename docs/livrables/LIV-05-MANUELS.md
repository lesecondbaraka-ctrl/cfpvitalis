# LIV-05 — Manuels de Prise en Main Utilisateurs

## Admin Centre
1. Se connecter avec `admin@vitalis-center.fr`
2. **Établissements** : créer/modifier/supprimer les antennes
3. **Utilisateurs** : activer/désactiver les comptes
4. **Analytics** : consulter les KPI globaux

## Admin Établissement
1. Se connecter avec `admin.lyon@vitalis-center.fr`
2. **Mon établissement** : stats locales (assiduité, complétion, moyennes)
3. **Utilisateurs établ.** : gérer les apprenants de son antenne

## Formateur
1. **Formations** : créer parcours, modules, cours
2. **Upload** : joindre un PDF à chaque cours
3. **Séances** : planifier et émarger électroniquement
4. **Notes** : saisir les évaluations par apprenant
5. **Certificats** : émettre si BR-03 validé (100% + moyenne ≥ 10/20)

## Apprenant
1. **Mes cours** : suivre la progression e-learning
2. Marquer les cours comme terminés
3. **Mes certificats** : télécharger le PDF officiel

## Personnel Administratif
1. **Assiduité** : consulter les taux de présence par apprenant

## Vérification publique
- URL : `/certificats/verifier/CERT-YYYY-XXXXX`
- Aucune connexion requise
